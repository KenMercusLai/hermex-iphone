# Sideload testing: Mac mini builds, MacBook Air installs

This fork's test IPA is compiled for a physical iPhone (`arm64`, iOS 18+) on the
Mac mini. Download it on the MacBook Air, then use **Sideloadly for macOS** from
<https://sideloadly.io/> to sign and install it with your own Apple Account.
The MacBook Air does not need Xcode; the Mac mini does not need Sideloadly.
Never share your Apple Account password in chat or a GitHub issue.

## Test-flavor limits

The IPA is **unsigned and requires re-signing**. It is not an App Store,
TestFlight, enterprise-signed or directly installable release. Free-account
signatures generally expire after seven days and require refresh/reinstallation.

The first test flavor includes the main app only. Share extensions, Live
Activities and remote push are not supported; the packaging tool removes the
embedded extensions, disables Live Activities and clears shared push Keychain
metadata in the staged bundle plist.
The original compiled `.app` is never changed. The fork uses its own bundle ID,
`com.kenmercuslai.hermex.iphone`, and display name `Hermex Test`, so it does not
replace the upstream App Store app. Signer-generated suffixes must remain stable
across updates if you want to keep this test app's local state.

Normal credentials use the default iOS Keychain group generated by signing, not
the upstream developer's shared push group. Login persistence and free-account
signing still require a real installation test; successful compilation and ZIP
validation do not prove those behaviors.

## Reproducible build and package

From the repository root with full Xcode installed:

```sh
export DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer
export TMPDIR="$HOME/.hermes/cache/scratch"
xcodebuild -project HermesMobile.xcodeproj -scheme HermesMobile \
  -configuration Release -destination 'generic/platform=iOS' \
  -derivedDataPath .build/Device \
  -clonedSourcePackagesDirPath .build/SourcePackages \
  -disableAutomaticPackageResolution -jobs 2 \
  CODE_SIGNING_ALLOWED=NO CODE_SIGNING_REQUIRED=NO DEVELOPMENT_TEAM= \
  APP_BUNDLE_IDENTIFIER=com.kenmercuslai.hermex.iphone \
  APP_GROUP_IDENTIFIER=group.com.kenmercuslai.hermex.iphone \
  'APP_DISPLAY_NAME=Hermex Test' APP_URL_SCHEME_SUFFIX=-ken APS_ENVIRONMENT= build
scripts/package-sideload \
  --app .build/Device/Build/Products/Release-iphoneos/HermesMobile.app \
  --output .build/sideload/Hermex-iPhone-test.ipa
```

Resolve pinned Swift packages first if no checkout cache exists. Use a new output
filename for each package; the tool refuses to overwrite an existing one.
Before upload, verify Mach-O `arm64` and `IOS` (not `IOSSIMULATOR`), minimum OS,
ZIP integrity, executable permissions, absence of `PlugIns`, and final SHA-256.
Publish the exact source commit and verification limitations alongside each IPA.

## Install on the MacBook Air

1. Download Sideloadly's macOS version from its official site and move the app to
   Applications. Download this fork's IPA and checksum from its GitHub prerelease.
2. Connect the unlocked iPhone with a data cable and accept Trust on both devices.
3. Open Sideloadly, select the iPhone, drag in the IPA and enter your own Apple
   Account. Use normal signing/installation; no jailbreak or injection is needed.
4. Follow Apple's account verification and device prompts in the tool/system UI.
   On the iPhone enable Developer Mode and trust the developer profile if prompted.
5. Open **Hermex Test**, enter the existing WebUI server and sign in. Verify that
   login survives a relaunch before testing Archive, Auto-name and Rename.

If installation or login fails, capture the precise error without including
passwords, tokens, private hostnames or conversation contents. Do not delete the
upstream app or alter the production server to work around a signing issue.
